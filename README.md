# Chordcraft

コードを並べて編集し、音を確かめながらアイデアを形にできるブラウザー向けのコードエディターです。コードの追加・並べ替え・移調・ボイシング編集を中心に、再生やコード進行の生成にも対応しています。

## 主な機能

- コードの追加、削除、並べ替え、差し替え、転回形やベース音の編集
- コード名やディグリー（例: `C Am F G`、`1 6 4 5`）から進行を入力
- テンポ、音色、オクターブを選んでブラウザー上で再生
- 進行の移調とコード構成音の鍵盤表示
- 王道進行などのプリセットや、キー・自然さ・複雑さ・意外性を指定した進行生成

## 動作環境

- Node.js（開発・ビルド用）
- Web Audio API に対応したモダンブラウザー

## セットアップ

```sh
npm ci
npm run dev
```

表示されたローカル URL をブラウザーで開いてください。コードの試聴には、ブラウザー上で再生操作を行う必要があります。

## コマンド

```sh
npm run dev      # 開発サーバーを起動
npm run build    # 型チェックを行い、本番用ファイルを dist/ に生成
npm run preview  # 本番ビルドをローカルで確認
npm test         # コード解析・ボイシングのテスト
```

## 進行生成について

進行生成は編集のアイデア出しに使えます。キー内のダイアトニックコードを基本に、トニック／サブドミナント／ドミナントの機能やコード間のつながりを使って候補を選びます。設定に応じて、借用和音、セカンダリードミナント、テンション、susコード、転回形なども取り入れます。

再生には Tone.js を使用します。コード進行は 4/4 拍子で、1コードを1小節ずつ再生します。

ピアノ音色には Salamander Grand Piano V3 のサンプルを使用しています。サンプルは Tone.js の公開音源 URL から必要時に読み込まれ、音源の作者は Alexander Holm、ライセンスは [CC BY 3.0](https://creativecommons.org/licenses/by/3.0/) です。クレジット: “Salamander Grand Piano V3” by Alexander Holm.
